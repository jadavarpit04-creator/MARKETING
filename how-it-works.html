The five-second workflow

No new workspace to learn. No prompt tab to keep open. Just this loop, hundreds of times a day.

STEP 01

Select anything, anywhere

Text in a doc, an error in a terminal, a table in a screenshot, a thread in your inbox. If you can select it — or point a screenshot at it — it can become context.

STEP 02

Press the global shortcut

Ctrl + Space on Windows, Option + Space on macOS. The floating command card appears over your current app in under 300 ms. Nothing to open, nothing to switch to.

STEP 03

Check your context chips

Selected text, clipboard, the active app, a screenshot and any MCP context arrive as removable chips. You see exactly what will be sent — and can remove any of it before running.

STEP 04

Say it, or type it

Dictate or type the instruction in plain words: “turn this into a polite follow-up”, “make this a table”, “file this as an issue”. Or run a saved Shortcut by name.

STEP 05

It lands where you work

The validated result is inserted straight into the focused field — accessibility insert first, with clipboard and typing fallbacks. Most simple transforms finish in under 5 seconds.

What the command card sees

Context is explicit and removable. Sensitive apps are blocked by default, and screenshots are only ever taken when you ask.

Under the hood, in plain English

The details people ask about after the first demo.

trigger
Ctrl + Space on Windows · Option + Space on macOS — rebindable in Settings. Command card target: under 300 ms.
context sources
Selected text, clipboard, active app & window, optional screenshot, and MCP context you explicitly connected. Every source arrives as a removable chip.
command input
Voice dictation or typed text. Saved Shortcuts run by name with a fixed tone and output format.
output
Validated text, Markdown, table, CSV/TSV or code. Simple transforms target under 5 seconds; screenshots under 10.
insertion
Accessibility insert, then clipboard paste, then keyboard simulation — target under 500 ms — with a safe copy-to-clipboard fallback.
blocked by default
Password managers, banking and finance apps, and private windows never provide context unless you change the rules yourself.
