Questions, answered

Is MCP included in every plan?

Personal MCP connections start on Pro (2 servers). Team includes 10 shared servers and Business 25, with admin controls and audit logs.

Can Zerthik ever write without asking me?

No. Write tools always require an explicit approval showing the exact payload. Read tools run only after you have connected the server and allowed them.

Which MCP servers work?

Any server that speaks the Model Context Protocol. Connect it, review its discovered tools, set permissions — done.

How a connection is set up

Four deliberate steps between “interesting” and “allowed”.

STEP 01

You add a server

Nothing is pre-connected. You (or your workspace admin) add an MCP server explicitly and authenticate if it needs it.

STEP 02

Tools are discovered, not granted

Zerthik lists every tool the server exposes. Discovery changes nothing — each tool still needs a permission from you.

STEP 03

You set the rules per tool

Reads can be allowed after connection. Writes always require approval. Destructive tools start blocked and stay blocked until an admin decides otherwise.

STEP 04

Every use is on the record

When Zerthik uses a tool, the action log captures the server, tool, payload summary, result — and who approved it, if approval was needed.
