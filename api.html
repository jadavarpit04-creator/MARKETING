Say it like you would out loud

The instruction is a plain sentence — “turn this error into an issue draft” — not a schema to memorise.

Validated in the middle

Format and facts are checked before the response leaves, with the backup model on standby.

Ready where it lands

Render it, store it, or insert it — the output arrives in the exact shape you asked for.

Keys that behave

Personal keys on Pro; team keys on Team and Business. Managed from the same place as your usage.

Shown once, stored hashed

A new key is displayed exactly once and stored only as a hash. Lose it? Revoke and mint another — old keys die instantly.

PERSONAL & TEAM

Bearer auth, nothing exotic

Send the key as an Authorization: Bearer header over HTTPS. Keys inherit the plan and workspace of whoever created them.

HTTPS ONLY

Revoke in one click

A leaked key is a revoked key. Revocation is immediate and logged, and usage after revocation is rejected.

Rate limits & usage

Limits are per key and reset every minute. Every successful transform counts as one AI action against the plan.

Pro
60 requests / minute · personal key · 1,000 actions a month
Team
120 requests / minute · team keys · 2,500 actions per user a month
Business
300 requests / minute · team keys · 6,000 actions per user a month
429 responses
Include a retry-after hint. Higher API limit add-on available at $19/mo.

Everything on the record

Logged per request

Status, latency, action ID and which key made the call — visible in usage for users and admins.

No surprise bills

Actions are prepaid by plan, not metered after the fact. When the allowance ends, requests stop — they do not quietly bill.

Validated or rejected

Responses are checked against the requested outputType. Malformed output triggers the backup model, not your error handler.

MCP workflows over the API

The API can trigger the same approval-based MCP workflows as the desktop app — under exactly the same rules.

Approvals still apply

A write triggered by API waits for a human approval just like one triggered by keyboard. The payload is shown in full.

Workspace permissions

Team keys act with the workspace's MCP permissions and role limits — never with more power than their owner.

Destructive stays blocked

Blocked tools are blocked for API callers too. There is no header, flag or plan that talks around it.

Reference details

The boring parts, written down — so integrations do not have to guess.

authentication
Authorization: Bearer <API key> over HTTPS. Invalid or revoked keys are rejected; revocation is immediate.
request body
JSON with command (string), context (object: selectedText, clipboard, activeApp, screenshot) and outputType (text · markdown · table · csv · code).
success response
id, status, outputType and output. One successful transform = one AI action against the key owner's plan.
rate limiting
60 / 120 / 300 requests per minute on Pro / Team / Business. Over the limit returns 429 with a retry hint.
model fallback
If the primary model times out or returns malformed output, the backup model answers instead — same request, still one action.
mcp workflows
API-triggered tool writes follow desktop rules: payload shown, human approval required, destructive tools blocked, everything logged.
