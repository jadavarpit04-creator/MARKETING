Anatomy of a Shortcut

Four small parts turn a sentence you keep typing into a command the whole team can run.

name
What you say or type to run it — “Issue from Error”, “The Polite Nudge”. Short names win.
instruction
The saved prompt in plain words, including what to keep, what to drop, and what never to invent.
tone
A reusable voice — calm support, crisp founder, formal legal — stored with the Shortcut, not re-typed every run.
output format
Locked to text, Markdown, table, CSV/TSV or code, so the result lands ready for its destination app.
sharing
Personal by default. On Team and Business, publish it to the workspace so everyone writes the same way.
runs in
Every app via the command card — select context, run the Shortcut by name, insert the result.
